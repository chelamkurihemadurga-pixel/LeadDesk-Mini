# LeadDesk-Mini

A full-stack Lead Management System built using React and Flask.

## Features

### User Side
- Submit lead details
- Capture name, email, budget, and message
- Form validation
- User-friendly lead submission form

### Admin Side
- Secure admin login authentication
- View all submitted leads
- Dashboard statistics
- Manage lead status

## Tech Stack

### Frontend
- React.js
- JavaScript
- CSS
- Axios
- Vite

### Backend
- Flask
- Python
- SQLite
- JWT Authentication
- Flask-CORS

## Project Structure

```
LeadDesk-Mini/
│
├── frontend/
│   └── React application
│
└── backend/
    └── Flask API
```

## How to Run

### Backend Setup

```bash
cd backend

pip install -r requirements.txt

python app.py
```

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

## API Features

- REST API using Flask
- JWT-based authentication
- SQLite database integration
- React and Flask communication using Axios
- CORS enabled
